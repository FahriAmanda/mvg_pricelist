# mvg_pricelist

Katalog Price List Resmi Mitra Visual Group (MVG) & Asia Visiotron.

- **Frontend:** Nuxt 4 (Vue 3, TypeScript, Tailwind CSS, shadcn-vue, Framer Motion)
- **Engine:** Nitro Server with Live Auto-Sync to Google Sheets (Interval Polling & SSE Stream)
- **Deployment:** PM2 on VPS (`pricelist.mitravisualgroup.com`) with Nginx Reverse Proxy & Cloudflare SSL
